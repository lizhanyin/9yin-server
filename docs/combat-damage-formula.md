# 伤害计算公式骨架（CombatFormulas）

结论先行：**玩家打怪与 BOSS 打玩家两条战斗链路已全部改走统一公式结算**（此前为 150/120/260 三个魔数）。
公式为社区实测逆向结论的工程化（官方从未公开服务端公式），系数集中在 `CombatFormulas` 常量区，待官方表接入后标定。

## 1. 公式定义

```
减伤%  = 20 · ln(外防 / 100) − 44          （社区对数拟合，上限夹 75%）
有效攻击 = 攻击 × (1 − 减伤%) + 破防        （破防无视减免）
伤害减免 = 每点减免属性固定减伤，10 点折 1 点伤害（Wiki：1 per 10 Reduction，受击方平减）
未命中率 = 10% + 15% × (闪避 − 命中)/(闪避 + 1)   （命中=闪避时 10%；闪避概率含闪避率%加成合计夹 24% 上限；命中率%加成直接抵扣，下限 0）
暴击率 = 5% + 10% × (暴击值 − 坚韧)/(暴击值 + 1) + 暴击率% − 被暴击率降低%
                                       （基础段等值含全 0 时 5%、渐近 15%；暴击率%加成无上限可到 100%；合计夹 [0,100%]；招架不免疫暴击）
暴击倍数 = 1 + max(0, 100% 基础暴伤 + 暴伤% − 对手暴伤减免%)   （加算叠加，括号内下限 0 → 暴击等于普伤）
招架穿透比 = 1 − 格挡值 / 化劲            （夹 [0,1]；化劲 ≤ 格挡值时完全挡下；基础格挡值 50 / 化劲近似 100 → 招架减半）
结算顺序：先掷未命中（miss 则伤害 0），命中后掷暴击、乘招架穿透比，
最后 floor − 平减值；保底 1 点（未命中/完全招架为 0）
```

## 2. 瘀血/血量双层（玩家承伤）

受击伤害的 **25% 进瘀血层（`hitHp`，上限 30% 最大血量，溢出转血量）**，75% 直接扣血量；
瘀血战斗中每秒消退 10 点（`PlayerActor.tick` 既有逻辑），复活清零。
官服比例未公开，`BRUISE_SPLIT_RATIO` / `BRUISE_CAP_RATIO` 为可调近似值。
BOSS 侧无双层结构，`SceneFlow` 中 NPC 直接扣血。

## 3. 招架体系（Parry Attributes）

- **218 消息开关招架**（`SceneFlow.handleActiveParry` → `PlayerActor.parrying`）；NPC 不招架。
- 招架结算在 `AiEventEngine.castSkill`：受击方招架且耐力 > 0 时，伤害乘穿透比
  `1 − 格挡值/化劲`（BOSS 化劲近似 100、玩家格挡值基础 50 → 减半；化劲 ≤ 格挡值完全挡下 0 伤害）。
- **招架耐力**：被招架的攻击按其攻击力扣耐力（`PlayerActor.drainParry`），归零即破招
  （后续攻击不再被招架），耐力每秒被动恢复（骨架默认上限 100 / 恢复 5 每秒，官服基础值未公开）。
- 招架与暴击独立：招架中的目标仍可被暴击（Wiki 明确）。
- 耐力/格挡值暂未同步客户端（PropertyId 未确认对应槽位），仅服务端结算 + 日志。

## 4. 默认值与兼容性

- 玩家默认 `attack=150`、防御/暴击全 0；BOSS 基准攻击 120（模板 attack 列缺省时），拼音大招（sxks/byft 等）按 `260/120` 放大。
- 命中/闪避默认全 0 时**双方每次攻击有 10% 基础未命中率**（Wiki 公式：命中=闪避 → 10%），未命中不掉血、不触发嗜血，但仍拉仇恨/进战斗窗口。测试经 `AiEventEngine.useRngForTest` 注入固定种子保证断言确定。
- 暴击默认全 0 时**双方每次命中另有 5% 基础暴击率**（Wiki 公式：暴击值=坚韧 → 5%，含全 0），基础暴伤 100% 即双倍伤害，BOSS 也会暴击玩家；招架不影响暴击。
- 招架默认：格挡值 50（Wiki 基础值）、化劲 100、耐力上限 100 / 每秒恢复 5（后三者为骨架近似）；玩家默认不招架，行为与之前一致。
- 防御类属性不会低于 0（减益最多压到 0）；Wiki 注明 **NPC 通常没有防御类属性**——与真实 npcconfig 无防御列互证，NPC 侧属性全走默认值。
- 属性命名对齐 Wiki：暴击值（Critical Hit，外功暴击 ← 臂力 1:1）、坚韧（Resilience，社区名封禁值，进暴击率公式）、暴击率%加成（无上限）、被暴击率降低%、暴伤%加成（加算）、暴伤减免%（受击方）、伤害减免（10 点折 1 伤）、格挡值（BlockRating）/化劲（InternalConversion）。
- `NpcTemplate` 新增 `attack/defense/accuracy/evasion` 可选列（识别 `AttackPower/Attack`、`Defence/Defense/WaiFang`、`Accuracy/Hit`、`Evasion/Dodge/Miss`），真实 npcconfig 无此列时为 0 走默认值。经查真实表（`clonenpc/bossnpc.txt`），攻防数值实际由 `ModifyPropID` / `PowerNo` 引用属性包表，见 §5。
- 命中/暴击均分内外功两种（外功 ← 身法/臂力 1:1，内功 ← 罡气 1:1，影响对应类型技能）；当前骨架只有外功伤害，内功变体接内功伤害时再加。

## 5. 后续接表路线（未做）

1. **NPC 属性**：解析 `ModifyPropID`（属性修改包）/ `PowerNo`（实力包）引用的属性表，替换 `bossStats` / `CombatStats.defender` 的默认值。
2. **玩家属性**：`PlayerActor` 的攻击/防御/命中/闪避/暴击/坚韧/暴伤/减免/格挡/化劲字段接装备、内功层数、经脉表（身法→外功命中、臂力→外功暴击、罡气→内功命中与内功暴击，均 1:1）。
3. **技能倍率**：`CombatFormulas.skillRatio` 目前恒 1.0；官方为每技能一条数据驱动公式（红/蓝/绿参数 × 施放者近战/内功强度），可参考 nineyinmanual.com 的逐技能逆向。
4. **内功防御四系**：内功防御（总）+ 刚/柔/阴/阳防御（百分比）与各自 Reduction（平减 1/10），接内功伤害时一并加。
5. **未命中/暴击扩展**：内功命中与内功暴击、PvP 角色强度对命中的修正、梯云纵/雁行功轻功动作期间的闪避加成、招架耐力的客户端同步槽位。
