经脉

每日真气硬闸：开启后当日已获真气（ZQPLValue，被动修炼 + 打怪折算同一池）达到阈值即停止入账，进度条停住，次日 UTC 日切自动恢复；关闭则不限量（进度条上限显示回落官方缺省 500）。设置为角色级持久化（重登沿用），修改立即下发属性帧。


洗练（身上装备 · 指定部位）

先选部位再点功能：随机洗练=词条属性+数值全随机重掷（op3）；定向洗练=保持现有词条属性不变，只在同属性族内随机重掷数值（op4）；抛光=保持词条属性不变，把每条数值拉到该属性族的最高档（组内最大值）。招式开光随机洗练已学招式词条。词条是全局属性包，穿在任何部位都生效；武器走 senior_weapon 专属池，防具/首饰走 senior_prop 专属池（防具定向/抛光在同内功同属性族内重掷），没有专属段时按家族前缀回退、仍没有才兜底全池。结果立即重刷装备视图、战斗加成并写入 equip.json。定向/抛光需要该部位已有词条。

门派

修改角色原生门派属性（School/Force/NewSchool）并持久化落库； 不自动赠送对应套路、身份装或任务线（身份装可用「外观」区另行激活）。

武学套路

把玩家已学会的全部武学套路（View=40 技能目录）按 skill_static varprop 满级一次性升满并填满修为，行帧刷 Level/MaxLevel/修为并重建可用性心跳；满级经 data/武学等级.json 落档重登保持。遗忘则回登录基线（DB 模式=基础五件套，starter 模式=初始套路集），清档、删 role_skills 武学行并摘除失效快捷栏。

修为

修为=修炼点余额（Faculty，内修每分钟折半消耗，种子 999 万），角色级持久化（role_faculty 快照，重登沿用）；修炼速度拆为基础值 × 倍率（默认 200 × 1，倍率可填小数），实际值走 FillSpeed、基础值走 NorFacultyAdd 同帧下发；普通内修态改速即时生效，停修/演武态下次开修生效。填满当前修炼内功的本层修炼度立即升一层（0x18 书帧 + 0x10 属性 + 191/14 升层提示），恰达满级自动停修。




演武碎银上限 0=不限制（ActDayValue 族随 0x10 下发；有限额时打卡超限静默拒绝）。团练疲劳=TeamFacultyValue（0..80000，客户端按剩余精力%显示），清除即恢复 100%。

风物志卡牌

基于 CardRec（按位记录收集）与 UseCardRec（已装备卡牌）。数据来自 data/card_models.json。点击卡牌名即可装备（ShowEquipType=2，优先显示卡牌模型）。


风物志头发

仅列出只含 Hat 部件的纯发型卡牌（helmet 头模，不含 Cloth/Pants/Shoes/Weapon）。点击「装备选中发型」会叠加在已有风物志之上，已装备的衣服/武器外形不会被替换。

五维属性

直接修改角色五维（臂力/体魄/身法/内息/罡气），改动后立即重算派生战斗属性并实时刷新客户端面板。留空或填 0 表示该维不修改。属性为覆盖式写入（非累加）。

称号管理

玩家初始无任何称号；发放/佩戴/取消均经服务端校验。称号 ID 与名称取自 data/称号数据.json 总表（客户端 role_title_* 文本）。佩戴即写入 TitleID 属性并刷新界面。

快捷栏位

存档/恢复玩家的快捷栏布局（数字键1-0、Ctrl+1-0、F1-F5等）。每次登录自动从 data/快捷栏位按键.json 读取；游戏内拖放技能时自动保存。

实力等级

设置玩家 PowerLevel（0–160），服务端自动按功力等级映射称号 LevelTitle 并刷新界面。

性格善恶

设置玩家 善值/恶值/基础狂邪，服务端自动计算性格标签（0正常 1侠 2恶 3狂 4邪）与性格数值并刷新界面。

体力 / 饱食 / 杀戮 / 酒量

一次性设置 9 项活力属性；当前体力/饱食默认填满至上限，上限加成默认 0。服务端刷新界面并持久化 save=true 项（体力/饱食/杀戮值/酒量等级）。
