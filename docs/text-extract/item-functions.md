## 关键机制线索

- **书页式投放**：高阶武学（降龙心法）按"书页第 N 页"拆分投放，通过奇遇奖励包随机获得指定页段。
- **图纸-改造链**：换装图纸收藏进图纸集 → 梳妆阁改造装备风格（外观系统与属性分离）。
- **宝物副套路**：宝物可指定/封存"副套路加成"，分解得兑换凭证——宝物是可循环资源。
- **经脉激活消耗**：激活经脉每分钟消耗 1000 修为（修为是持续消耗型资源）。
- **配方获取链**：武器配方 ← 铁匠购买或铁匠引导任务；药品配方 ← 江湖营帐江湖随从。
